# Дело о пропавших данных

Интерактивный текстовый квест по Apache Iceberg.

## О квесте

Понедельник, твой первый рабочий день, но аналитики уже потеряли таблицу. Хорошо, что за данными следит Iceberg. Или нет?

Нужно разобраться, пока кофе ещё тёплый.

По ходу расследования предстоит разобраться с ключевыми концепциями Apache Iceberg: снапшоты, time travel, schema evolution, ACID-транзакции. Концовка зависит от того, насколько точно удастся понять, что произошло.

## Концовки

Всего их три — зависят от правильности ответов в ключевых моментах.

## Как запустить

Игра доступна онлайн: [GitHub Pages](https://awariel7.github.io/Iceberg_quest/)

Или локально — открыть `index.html` в браузере.
